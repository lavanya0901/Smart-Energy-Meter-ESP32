# Smart Energy Meter – Design Registration Project

## Overview

The Smart Energy Meter is a product design project focused on developing a compact and user-friendly energy monitoring device enclosure. The project resulted in a registered design showcasing the external appearance and configuration of the meter.

The objective was to create a modern energy meter housing suitable for future integration with embedded electronics, sensing modules, wireless communication systems, and smart monitoring features.

---

## Design Features

* Compact industrial design
* Front display provision
* Status indicator section
* Secure terminal connection area
* Wall-mountable enclosure
* Ventilation structure for thermal management
* Ergonomic and professional appearance

## Proposed Technical Features

The enclosure is designed to support future embedded system integration such as:

* ESP32 Microcontroller
* Current and Voltage Sensors
* LCD/OLED Display
* Wi-Fi Connectivity
* IoT Monitoring
* Real-Time Energy Measurement
* Mobile Application Integration
* Cloud Data Logging
